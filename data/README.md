# data/

Каталог данных проекта. Содержимое (кроме этого файла) не ходит в git и не
синкается на сервер целиком — только распарсенные `*.txt` (см. `.rsyncignore`).

## Структура

| Путь | Что это |
|---|---|
| `tolstoy-tei/` | TEI/XML-корпус «Все Толстые» (https://github.com/tolstoydigital/TEI, CC BY-SA), sparse-клон только `texts/letters` + `texts/diaries`. Скачивается/обновляется через `make tei-fetch`. |
| `tei_letters.txt` | Письма (9 тыс.), распарсенные `make convert` из TEI — формат `### META \| k=v` + абзацы |
| `tei_diaries.txt` | Дневники (4.3 тыс. записей), аналогично |
| `tom01–45.txt` | Проза из 90-томного собрания (EPUB), legacy — до перевода прозы на TEI works |
| `unused_tom/` | Вытесненные TEI'ем EPUB-тома 46–90 (письма/дневники) — вне корпуса |
| `90 томов Толстого/`, `Толстой Л.Н. в 22 томах …/` | Исходные EPUB (не в git, не на сервере) |

## Пересборка

```bash
make tei        # обновить TEI-корпус и переконвертировать
make embeddings # пересобрать индекс из data/*.txt
```
