# Каталог данных

Сюда кладутся исходные тексты для сборки индекса. **Файлы данных не входят
в репозиторий** (см. `.gitignore`) — по двум причинам:

1. Конкретные издания могут быть под авторским правом (тексты Толстого —
   общественное достояние, но редактура, комментарии и вёрстка издания — нет).
2. Это крупные бинарники, не место которым в git.

## Что положить

Проект рассчитан на собрание сочинений Л. Н. Толстого в EPUB. Парсер 
(`scripts/epub_to_txt.py`) обрабатывает все тома с номером в названии файла:

- **1–17** — художественные произведения, публицистика (извлекается весь текст);
- **18–20** — письма (с метаданными: адресат, дата, номер);
- **21–22** — дневники (с метаданными: год, дата).

Положите EPUB-файлы сюда (имя должно содержать «Том NN», напр.
`… Том 18 ….epub`), затем локально:

```bash
make convert      # EPUB → data/*.txt (все найденные тома)
make embeddings   # data/*.txt → index/vectors.npy + index/chunks.json
```

Скрипт автоматически определяет тип тома: для томов 18-22 парсит детальную
структуру (письма/дневники), для остальных извлекает весь текст целиком.
