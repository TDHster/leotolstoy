# data/

Каталог данных проекта. Содержимое (кроме этого файла) не ходит в git. На
сервер синкается только то, что читает корпус: 5 основных jsonl из `verbatis/`
(остальные форматы и каталоги исключены в `.rsyncignore`).

## Структура

| Путь | Что это |
|---|---|
| `verbatis/` | **Единственный источник текстов** — клон приватного репозитория [Verbatis](https://github.com/Nikulov-IB/Verbatis) (ПСС-90, обработанные тексты). Корпус читает только `verbatis/data/raw/tolstoy/tolstoy_*.jsonl` (письма, дневники, записные книжки, статьи, трактаты). Клонируется/обновляется через `make verbatis-fetch`. |
| `90 томов Толстого/` | Архив (для истории/отката): 90 EPUB исходного издания + legacy-файлы `tom01–45.txt` (проза из EPUB) и `tei_letters.txt`/`tei_diaries.txt` (конвертация TEI, заменена Verbatis'ом). Корпусом не читается, на сервер не едет. |
| `tolstoy-tei/` | TEI/XML-корпус «Все Толстые» (tolstoydigital, CC BY-SA) — legacy-источник до перехода на Verbatis; корпусом не читается |
| `unused_tom/` | Вытесненные TEI'ем EPUB-тома 46–90 (письма/дневники) — вне корпуса |
| `Толстой Л.Н. в 22 томах …/` | Исходные EPUB издания 1978 г. (не в git, не на сервере) |

## Пересборка

```bash
make verbatis-fetch # обновить корпус Verbatis (git clone/pull)
make embeddings     # пересобрать индекс из data/verbatis/*.jsonl
```
